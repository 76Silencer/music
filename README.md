# Vue 3 纯前端音乐播放器

这是一个基于 **Vue 3 (Composition API)** 和 **Vite** 构建的纯前端音乐播放器网站。它拥有类似桌面端音乐软件的现代化布局设计、深色毛玻璃 UI 风格，并支持本地音频库扫描与高清无损音乐播放。

## ✨ 核心特性

- 🎵 **纯前端纯本地**：无需后端服务器，音乐文件直接放置在本地项目中。
- 🔍 **智能本地曲库扫描**：通过内置的 Node.js 脚本，在项目启动或打包前自动扫描 `public/music/` 目录下的音频文件生成曲库配置。
- 🎧 **播放控制与模式**：支持上一首、下一首、播放/暂停、进度条拖拽、音量调节；支持单曲循环、列表循环、随机播放等经典播放模式。
- 🎶 **高清无损支持**：原生支持 `.mp3`、`.flac` 格式。
- 📜 **动态歌词解析与展示**：自动读取与音频同名的 `.lrc` 歌词文件，支持 UTF-8 和 GBK 编码防乱码，提供歌词滚动高亮、手动滑动、点选歌词直接空降播放功能。
- 🔄 **播放列表拖拽排序**：支持播放列表内拖拽调整歌曲播放顺序，移除歌曲及防重复添加保护机制。
- 🔎 **实时搜索**：曲库和播放列表均内置搜索框，支持歌名/歌手名即时过滤。
- 💿 **沉浸式歌词详情页**：点击左下角正在播放的封面，可展开全屏歌词详情页，带有动态旋转的黑胶唱片特效和沉浸式的歌词滚动体验。

## 🛠 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **核心组件**: HTML5 `<audio>` API
- **样式**: 纯 CSS (Flexbox, CSS Variables, Backdrop-filter) 现代化极简深色主题

## 🚀 如何运行与开发

### 1. 安装依赖
```bash
npm install
```

### 2. 添加你的音乐文件
将你喜欢的 `.mp3` 或 `.flac` 以及同名的 `.lrc` 歌词文件放到 `public/music/` 目录下。
*(注：项目中已配置了对该目录的 Git 忽略，因此你的本地私有音乐文件不会被误提交到仓库中。)*

推荐命名格式：`歌手名 - 歌曲名.mp3`，系统会自动解析。

### 3. 启动开发服务器
```bash
npm run dev
```
启动时，内置脚本会自动扫描 `public/music/` 目录，生成最新的曲库供前端读取。

### 4. 构建生产环境
```bash
npm run build
```
打包前同样会自动扫描最新的音乐文件进行配置。打包完成后可以部署 `dist` 目录。

## 📝 目录结构简析

```text
├── public/
│   └── music/           # 放置你的 mp3/flac 和 lrc 文件的地方
├── src/
│   ├── components/      # UI 组件
│   │   ├── PlayList.vue       # 右侧播放列表
│   │   ├── PlayerControls.vue # 底部播放控制栏
│   │   ├── SongDetail.vue     # 沉浸式歌词详情页
│   │   └── SongLibrary.vue    # 左侧大曲库
│   ├── composables/     # 复用逻辑
│   │   └── useAudioPlayer.js  # 核心全局播放控制状态管理与底层逻辑
│   ├── data/            # 自动生成的静态数据配置
│   ├── App.vue          # 主页面布局容器
│   └── main.js          # 项目入口
├── generate-songs.js    # Node.js 音乐目录扫描脚本
└── package.json         # 项目配置与脚本钩子
```
